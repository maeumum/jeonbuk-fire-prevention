# 전북 전기화재 예방 우선지원 모델

2026년 제4회 전북 청년 AI·빅데이터 경진대회 출품작

전북특별자치도 14개 시군의 전기화재 데이터를 분석하여, 한정된 예방 자원을 어느 지역에 먼저 투입해야 하는지 결정하는 우선지원 모델입니다.

**배포 주소**: https://jeonbuk-fire-prevention-sjxchvgowsmczyyed5a58c.streamlit.app/

---

## 주요 기능

- 전국 시도 대비 전북 전기화재 현황 비교
- 14개 시군 연도별(2021~2025) 전기화재 건수 추이
- 종합위험점수 기반 시군별 우선순위 산출
- 고령 1인가구 밀도·노후주택 등 변수와 전기화재율의 상관관계 검증
- OLS 회귀분석으로 전기화재율 설명변수 규명
- K-means 클러스터링(k=3)으로 고위험·중위험·관리 등급 분류
- Folium 지도로 시군별 위험도·비상소화장치·소방서 위치 시각화
- 비상소화장치 자원배분 갭 분석 시뮬레이터
- 시군별 맞춤 AI 예방정책 브리핑
