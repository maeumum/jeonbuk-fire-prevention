## 2. 파일별 상세 설명

### 2.1 fire_raw.csv
전북 14개 시군의 연도별 전기화재 건수 및 재산피해.

| 컬럼 | 설명 |
|---|---|
| 시군 | 전북 14개 시군명 |
| 연도 | 2021~2025 |
| 화재건수 | 해당 연도 전기화재 발생 건수 |
| 재산피해_천원 | 해당 연도 재산피해액 (단위: 천원) |

> **전처리**: 2021년 전주시는 원본 데이터에 완산구·덕진구로 분리 기재 → 합산하여 전주시로 통합.

---

### 2.2 summary.csv
14개 시군의 5개년(2021~2025) 평균값 기반 종합 지표. 분석의 핵심 데이터프레임.

| 컬럼 | 설명 | 단위 |
|---|---|---|
| 시군 | 전북 14개 시군 | - |
| 평균화재건수 | 5개년 평균 화재 건수 | 건 |
| 총주택수 | 시군 내 총 주택 수 | 호 |
| 천호당화재율 | 평균화재건수 / 총주택수 × 1000 | 건/천호 |
| 평균피해액_천원 | 5개년 평균 재산피해액 | 천원 |
| 노후주택비율 | 30년 이상 노후주택 비율 | % |
| 고령1인가구비율 | 65세 이상 1인가구 비율 | % |
| 고령1인가구밀도 | 65세 이상 1인가구 수 / 총주택수 × 1000 | 명/천호 |
| 고령단독주택거주율 | 고령 1인가구 중 단독주택 거주 비율 | % |
| rank_화재율 | 천호당화재율 순위 | 1~14 |
| rank_피해액 | 평균피해액 순위 | 1~14 |
| rank_고령밀도 | 고령1인가구밀도 순위 | 1~14 |
| 종합위험점수 | rank 3개 합산 | 점 (낮을수록 시급) |
| 우선순위 | 종합위험점수 순위 | 1~14 |
| rank_단독거주율 | 고령단독주택거주율 순위 | 1~14 |

### 2.4 fire_cause_by_year.csv
전국 전기화재 발화원인별 연도 통계. 회귀분석 배경 자료.

| 컬럼 | 설명 |
|---|---|
| 연도 | 2022~2025 |
| 발화 원인 | 절연열화에 의한 단락, 트래킹 등 |
| 화재 건수 | 건 |
| 점유율 | 전체 전기화재 대비 비율 (%) |

---

### 2.5 sido_fire.csv
한국전기안전공사 시도별 전기화재 발생 현황. 전국 비교 분석에 사용.

- 컬럼 구조: 시도명 + 연도별(2022·2023·2024) 건수·피해액 등 반복 구조
- 전처리: 1행(컬럼명)·전국 합계 행 제외, 연도별 건수 컬럼 추출

---

### 2.6 정기점검_행정구역별.csv
한국전기안전공사 정기점검 실시 현황. 역설(부적합률 평균 수준 vs 높은 화재율) 분석에 사용.

| 컬럼 | 설명 |
|---|---|
| 행정구역별 | 시도명 |
| 연도 | 2016~2025 (2019년 기준변경 제외) |
| 부적합률 | 정기점검 중 부적합 판정 비율 (%) |

> **전처리**: 2019년은 전국 기준 변경으로 이상치 발생 → 분석에서 제외.

---

### 2.7 노후주택현황.csv
국토교통부 건축물 현황. 노후단독주택비율 산출에 사용.

| 컬럼 | 설명 |
|---|---|
| 시군구 | 시군구명 (전주시 완산구/덕진구 포함) |
| 단독주택 | 30년 이상 노후 단독주택 수 |
| 합계 | 전체 노후주택 수 |

> **전처리**: 전주시완산구·전주시덕진구 → 전주시로 합산.

---

### 2.8 비상소화장치현황.csv
전북특별자치도 비상소화장치 설치 위치 및 좌표. 지도 시각화 및 갭 분석에 사용.

| 컬럼 | 설명 |
|---|---|
| 설치위치 | 주소 (전북특별자치도 ○○시/군 포함) |
| 위도 / 경도 | GPS 좌표 |
| 시군 | 정규식으로 추출한 시군명 |

> **전처리**: 설치위치에서 정규식(`전북특별자치도 (\S+시|\S+군)`)으로 시군명 추출.

---

### 2.9 전국소방서_좌표.csv
소방청 전국 소방서·119안전센터 좌표. 지도 시각화에 사용. 전북 해당 행만 필터링.

---

### 2.10 kosis_elderly_single_household.csv
통계청 KOSIS 연령별·행정구역별 1인가구 수. 고령화 추이 분석에 사용.

| 주요 컬럼 | 설명 |
|---|---|
| 행정구역별(시군구) | 전북 포함 여부로 필터링 |
| 성별 | "계" 행만 사용 |
| 항목 | "1인가구" 행만 사용 |
| 연령별 | 65~69세, 70~74세, 75~79세, 80~84세, 85세이상 합산 |
| 2020 년 ~ 2025 년 | 연도별 가구 수 (쉼표 포함 문자열 → 숫자 변환 필요) |

> **전처리**: 연도 컬럼 쉼표 제거 후 `pd.to_numeric()` 변환 필수.

---

### 2.11 population_projection_2052.csv
통계청 장래인구추계 전북 2052년 중위 시나리오. 고령화 전망 지표에 사용.

| 컬럼 | 설명 |
|---|---|
| 시도별(1) | "전북" 포함 행 필터링 |
| 인구종류별(1) | 고령인구(천명): 65세+, 구성비(%): 65세+ |
| 2052 | 2052년 예측값 |

## 3. 데이터 흐름

```
[원본 데이터]                    [산출 지표]
전기화재_지역별.csv  ─────────►  fire_raw.csv
                                  ↓
                              summary.csv (천호당화재율, 종합위험점수, 우선순위)
                                  ↓
노후주택현황.csv ────────────►  노후단독주택비율 (동적 계산)
                                  ↓
kosis_elderly*.csv ─────────►  고령단독주택거주율 (summary.csv 원본 컬럼)
```

## 4. 데이터 품질 이슈 및 해결

| 이슈 | 해결 방법 |
|---|---|
| 2021년 전주시 완산구·덕진구 분리 기재 | 두 구 합산 후 전주시로 통합 |
| 2019년 정기점검 기준 변경으로 이상치 | 해당 연도 분석 제외 |
| kosis 파일 숫자에 쉼표 포함 (문자열) | str.replace(",", "") 후 pd.to_numeric 변환 |
| 비상소화장치 시군 정보 없음 | 설치위치 주소에서 정규식으로 추출 |
