# 최종 결과보고서

## 전북 화재 예방 우선지원 모델
**2026년 제4회 전북 청년 AI·빅데이터 경진대회 출품작**

---

## 1. 프로젝트 개요

### 1.1 분석 목적
전북특별자치도 14개 시군의 전기화재 데이터를 분석하여, 한정된 예방 자원(인력·장비)을 어느 지역에 먼저 투입해야 하는지 데이터 기반으로 결정하는 우선지원 모델을 구축한다.

### 1.2 분석 배경
- 전북 인구 10만명당 전기화재 건수는 전국 상위권 수준
- 전기안전 정기점검 부적합률은 전국 평균 수준임에도 화재율이 높음
- 기존 점검 체계가 고령 1인가구 단독주택에 충분히 닿지 못하고 있다는 구조적 문제 존재

### 1.3 분석 범위
- **대상 지역**: 전북특별자치도 14개 시군
- **분석 기간**: 2021~2025년 (5개년)
- **분석 도구**: Python 3.13, Streamlit, scikit-learn, statsmodels, Anthropic Claude API

## 3. 분석 방법론

### 3.1 종합위험점수 산출
화재율·재산피해액·고령1인가구밀도 3개 지표의 순위를 합산하여 시군별 종합위험점수를 산출하고 우선순위를 부여했다.

```
종합위험점수 = rank(천호당화재율) + rank(평균재산피해액) + rank(고령1인가구밀도)
```

### 3.2 상관관계 분석 — 4단계 가설 검증

| 가설 | 변수 | 상관계수(r) | 결과 |
|---|---|---|---|
| 가설 1 | 노후주택비율 전체 | 0.152 | 기각 (아파트 포함 희석) |
| 가설 2 | 노후단독주택비율 | 0.37 | 부분 지지 |
| 가설 3 | 고령1인가구밀도 | 0.801 | 강한 상관 |
| 가설 4 ✅ | 고령단독주택거주율 | **0.854** | 최강 설명력 채택 |

### 3.3 회귀분석 (OLS)

**최종 모형**: 천호당 화재율 ~ 고령 1인가구 단독주택 거주율

| 통계량 | 값 |
|---|---|
| 상관계수 (r) | 0.854 |
| 결정계수 (R²) | 0.730 |
| p-value | 0.0001 |
| 표본 | 14개 시군 |

> 고령 1인가구 단독주택 거주율이 1%p 높아질 때마다 천호당 전기화재 건수가 통계적으로 유의하게 증가한다.

**다중공선성 검증**: 고령1인가구밀도 + 노후주택비율 동시 투입 시, 노후주택비율은 p=0.09로 유의하지 않음 → 허위상관 확인.

### 3.4 K-means 클러스터링 (비지도학습)

- **특성**: 고령단독주택거주율, 천호당화재율, 고령1인가구밀도 (3개)
- **클러스터 수**: k=3
- **실루엣 점수**: 0.45 (0.4 이상 = 유의미한 분리)
- **레이블 매핑**: 천호당화재율 평균 내림차순으로 고위험·중위험·관리 등급 고정

### 3.5 생성형 AI 브리핑 (Anthropic Claude claude-sonnet-4-6)
시군별 데이터(ML 등급, 자원배분 갭, 화재율, 고령 지표)를 포함한 구조화 프롬프트를 사용하여 진단 요약·우선 개입 3가지·근거를 포함한 브리핑을 스트리밍으로 생성.

## 4. 핵심 발견

### 4.1 기존 점검 체계의 사각지대
전북 전기안전 정기점검 부적합률은 전국 평균 수준이지만 화재율은 전국 상위권. 기존 점검(주로 상업·사업용 설비 대상)이 **고령 1인가구 단독주택**에 닿지 않고 있음을 시사.

### 4.2 단독주택 거주 구조가 핵심 위험 요인
아파트는 관리사무소가 배선을 점검하지만 단독주택은 거주자 본인이 관리해야 한다. 고령 1인가구가 단독주택에 집중적으로 거주하면서 배선 관리가 방치되는 것이 화재로 이어지는 핵심 메커니즘.

### 4.3 위험과 자원의 불일치
K-means 고위험 등급이면서 비상소화장치 밀도가 전북 중앙값 미만인 시군 존재 → 위험도와 인프라 배치가 불일치.

### 4.4 우선순위 상위 시군

| 순위 | 시군 | 천호당화재율 | ML 등급 |
|---|---|---|---|
| 1 | 진안군 | 1.152건 | 고위험 |
| 1 | 남원시 | 0.899건 | 고위험 |
| 3 | 임실군 | 1.155건 | 고위험 |
| 4 | 김제시 | 0.800건 | 중위험 |

## 5. 예방 전략 (정책 제언)

### POLICY 01 — 찾아가는 전기안전 점검 우선 배정
우선순위 상위 시군의 고령 1인가구 단독주택을 대상으로 한국전기안전공사 무료 방문 점검을 우선 배정. 경로당·복지관 연계 신청 접수 체계 구축.

### POLICY 02 — 비상소화장치 갭 지역 우선 보강
ML 고위험 + 장치밀도 부족 지역에 비상소화장치 추가 배치. 소방관서가 1~2개인 진안·임실·무주·순창은 대응 시간 보완책 병행 필요.

### POLICY 03 — 노후 배선 교체비 지원 확대
전기화재 주원인(절연열화·트래킹)은 노후 배선 교체로 직접 예방 가능. 저소득 고령 1인가구 대상 배선·누전차단기 교체비 지원사업을 우선순위 상위 시군에 집중 배정.

- 표본이 14개 시군으로 소수 → 신뢰구간이 넓고, 읍면동 단위 세분화 데이터로 재검증 필요
- 고령단독주택거주율과 고령1인가구밀도 간 다중공선성(r≈0.85) 존재
- 상관관계·회귀분석이며 직접적인 인과관계 증명은 아님
- K-means 클러스터 경계는 패턴 참고용 (n=14 소표본)
- 정책 효과는 사업 시행 후 데이터로 재보정 필요
