## 3. 설치 방법

### 3.1 저장소 클론 (또는 파일 다운로드)
```bash
cd 전북_전기화재_대시보드
```

### 3.2 가상환경 생성 (권장)
```bash
# macOS / Linux
python3 -m venv venv

# Windows
python -m venv venv
venv\Scripts\activate
```

### 3.3 패키지 설치
```bash
pip install -r requirements.txt
```

## 4. 환경변수 설정 (API 키)

AI 브리핑 기능을 사용하려면 Anthropic API 키가 필요합니다. 실행 방식(로컬/클라우드)에 따라 설정 방법이 다릅니다.

### 4.1 로컬 실행 시 — .env 파일

프로젝트 루트에 `.env` 파일을 생성합니다.

```bash
cp .env.example .env
```

`.env` 파일을 텍스트 편집기로 열고 API 키를 입력합니다.

```
ANTHROPIC_API_KEY=sk-ant-여기에_실제_키를_입력하세요
```

> **보안 주의**: `.env` 파일은 `.gitignore`에 포함되어 있어 git에 업로드되지 않습니다.
> API 키는 [Anthropic Console](https://console.anthropic.com)에서 발급받을 수 있습니다.

> **주의**: `.env` 파일을 수정한 후에는 Streamlit 앱을 재시작해야 반영됩니다.

### 4.2 Streamlit Cloud 배포 시 — Secrets 설정

배포 환경에서는 `.env` 파일 대신 Streamlit Cloud의 Secrets 기능을 사용합니다.

1. [share.streamlit.io](https://share.streamlit.io) 접속 → 해당 앱 선택
2. **Settings → Secrets** 클릭
3. 아래 내용을 입력하고 저장

```toml
ANTHROPIC_API_KEY = "sk-ant-여기에_실제_키를_입력하세요"
```

> **주의**: 값은 반드시 큰따옴표(`"`)로 감싸야 합니다. 저장 후 앱이 자동 재시작됩니다.

### 4.3 API 키 없이 실행
API 키가 없어도 앱은 정상 실행됩니다. AI 브리핑 버튼 클릭 시 규칙 기반 템플릿 브리핑으로 대체됩니다.

## 5. 앱 실행

```bash
# 프로젝트 루트 디렉토리에서 실행
streamlit run app.py
```

실행 후 브라우저에서 자동으로 `http://localhost:8501`이 열립니다.

> **주의**: `app.py`가 있는 디렉토리에서 실행해야 합니다. 다른 디렉토리에서 실행하면 data 폴더를 찾지 못합니다.

### 포트 변경이 필요한 경우
```bash
streamlit run app.py --server.port 8502
```

## 7. 자주 발생하는 오류 및 해결

| 오류 | 원인 | 해결 방법 |
|---|---|---|
| `ModuleNotFoundError` | 패키지 미설치 | `pip install -r requirements.txt` |
| `FileNotFoundError: data/...` | 실행 위치 오류 | app.py가 있는 디렉토리에서 실행 |
| `OverflowError: Python int too large` | CSV 숫자에 쉼표 포함 | 코드에서 자동 처리됨 (정상) |
| `ValueError: Unknown format code 'd'` | float에 정수 포맷 적용 | 코드에서 자동 처리됨 (정상) |
| AI 브리핑 오류 | API 키 미설정 또는 만료 | `.env`에서 API 키 확인 |
| `streamlit_folium` 없음 | 패키지 미설치 | `pip install streamlit-folium` |
