## 3. 주요 함수 설명

### 3.1 데이터 로드 함수

```python
@st.cache_data
def load_data() -> (DataFrame, DataFrame)
```
`fire_raw.csv`와 `summary.csv`를 로드. `@st.cache_data`로 캐시하여 재실행 시 재로드 방지.

```python
@st.cache_data
def load_fire_devices() -> DataFrame
```
비상소화장치 현황 로드. 설치위치 주소에서 정규식으로 시군명 추출.

```python
@st.cache_data
def load_fire_stations() -> DataFrame
```
전국 소방서 좌표 로드. 전북 해당 행 필터링 후 시군명 추출.

---

### 3.2 분석 함수

```python
@st.cache_resource
def fit_regression(df: DataFrame) -> (OLSResults, OLSResults, OLSResults)
```
3단계 OLS 회귀 모형 적합.
- `m_simple`: 고령1인가구밀도 단순회귀 (STEP 2)
- `m_multi`: 고령1인가구밀도 + 노후주택비율 다중회귀 (허위상관 검증용)
- `m_new`: 고령단독주택거주율 단순회귀 (STEP 3, 최종 모형)

```python
@st.cache_data
def run_kmeans(df: DataFrame) -> (DataFrame, float)
```
K-means 비지도학습 위험 등급 분류.
- 특성: 고령단독주택거주율, 천호당화재율, 고령1인가구밀도
- StandardScaler 표준화 후 k=3 클러스터링
- 천호당화재율 평균 내림차순으로 레이블 고정(고위험/중위험/관리) → 재실행해도 일관성 유지
- 반환: 클러스터 결과 DataFrame + 실루엣 점수

---

### 3.3 시각화 함수

```python
def render_folium_map(summary_df, device_df, station_df, city_coords,
                      show_devices, show_stations, show_centers) -> folium.Map
```
전북 지도 렌더링.
- 시군 위험 원(Circle): 종합위험점수 비례 반경, 우선순위 등급별 색상
- 비상소화장치: 파란색 CircleMarker
- 소방서: 진빨간색 CircleMarker
- `folium.FeatureGroup`으로 레이어 분리

---

### 3.4 AI 브리핑 함수

```python
def call_llm(region: str, row: Series, api_key: str = None) -> Generator
```
Anthropic claude-sonnet-4-6 스트리밍 연동.
- 시군별 데이터(ML 등급, 비상소화장치 밀도, 전북 평균 대비 수치 포함)를 구조화 프롬프트로 전송
- `client.messages.stream()`으로 토큰 단위 스트리밍 generator 반환
- `st.write_stream()`으로 실시간 출력

```python
def template_briefing(region: str, row: Series) -> str
```
API 키 미설정 시 규칙 기반 대체 브리핑 반환.

## 6. 주의사항

- `app.py`는 반드시 프로젝트 루트에서 실행해야 합니다 (`BASE_DIR = Path(__file__).resolve().parent` 기준으로 data 폴더를 찾음)
- `gap_df`는 섹션 8(시뮬레이터)에서 정의되며 섹션 9, 10에서 사용됩니다 — 코드 순서 변경 시 주의
- `jeonbuk_rank` 등 전국 비교 변수는 섹션 1에서 정의됩니다
- `st.cache_resource`를 사용한 `fit_regression()`은 앱 재시작 시에만 재계산됩니다
